# Джарвис — голосовой помощник для Android

Слушает в фоне слово «Джарвис» и управляет музыкой: Яндекс Музыка, плеер Lane, громкость, пауза, переключение треков.

## Команды

| Фраза | Что делает |
|---|---|
| Джарвис, включи яндекс музыку | Открывает Яндекс Музыку |
| Джарвис, включи яндекс музыку Numb | Ищет и включает трек |
| Джарвис, включи в лейне Numb | То же в Lane |
| Джарвис, включи Numb | Трек в Яндекс Музыке (по умолчанию) |
| Джарвис, громче / тише | Громкость |
| Джарвис, стоп / продолжи | Пауза / воспроизведение |
| Джарвис, дальше / назад | Следующий / предыдущий трек |

Можно сказать просто «Джарвис», дождаться ответа «Слушаю» и в течение 7 секунд сказать команду.

## Как собрать и поставить

1. Установи Android Studio.
2. File → Open → выбери папку `jarvis`, дождись Gradle Sync.
3. Включи на телефоне «Режим разработчика» и «Отладку по USB», подключи телефон.
4. Нажми Run (зелёный треугольник).
5. В приложении: «Запустить Джарвиса» → разреши микрофон → разреши «Поверх других приложений» → снова «Запустить».
6. Отключи оптимизацию батареи для приложения (Настройки → Приложения → Джарвис → Батарея → Без ограничений), иначе система может его усыпить.

## Важно знать

- **Проект не собирался и не тестировался на телефоне.** Я написал его без Android SDK, возможны мелкие ошибки при первой сборке.
- **«Джарвис» ловится обычным распознаванием речи Google**, а не настоящим wake-word движком. Работает, но нужен интернет, чуть тратит батарею и иногда пропускает слово. Для надёжности можно заменить на Picovoice Porcupine (нужен бесплатный ключ).
- **Поиск трека** идёт через стандартную команду Android «включить по поиску». Я не знаю наверняка, принимает ли её Яндекс Музыка и Lane. Если не принимают, приложение просто откроется без трека. В этом случае скажи, что получилось, и я подберу другой способ.
- **Lane ищется по названию** среди установленных приложений («Lane»). Если на телефоне оно называется иначе, поменяй `LANE_LABEL` в `MusicController.kt`.
- Разрешение «Поверх других приложений» нужно, чтобы Android позволил сервису открывать плеер из фона.
- Пауза, громкость и переключение треков работают через системные медиа-клавиши, то есть с любым плеером, который сейчас играет.
